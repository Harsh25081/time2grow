# Scene Script Patterns

## Refrigerator / Electronics Store

Common angles:

- Summer heat problem -> family visits showroom -> refrigerator options -> exchange/EMI -> happy home.
- Old fridge not cooling -> Satya Electronics solution -> delivery/install -> cold water/food freshness payoff.
- Festival offer -> family shopping -> trusted showroom -> deal closes.

Useful Telugu lines:

- "ఈ వేసవిలో చల్లదనం ఇంటికే రావాలి."
- "పాత ఫ్రిజ్‌తో ఇబ్బంది పడుతున్నారా?"
- "సులభమైన EMI, ఎక్స్చేంజ్ ఆఫర్, నమ్మకమైన సర్వీస్."
- "సత్య ఎలక్ట్రానిక్స్ - మీ ఇంటి appliances కి నమ్మకమైన అడ్రస్."

## Jewelry

Common angles:

- Wedding preparation -> bride/family wants perfect set -> showroom reveal -> trust/purity/design -> emotional ending.
- Festival shopping -> mother/daughter choose jewelry -> offer/trust -> family celebration.
- Surprise gift -> husband/family buys jewelry -> emotional reveal.

Useful Telugu lines:

- "ప్రతి పెళ్లి క్షణానికి మెరుపు కావాలి."
- "నమ్మకమైన బంగారం, అందమైన డిజైన్స్, మీ బడ్జెట్‌కు సరిపోయే కలెక్షన్స్."
- "మీ ఆనందానికి బంగారు గుర్తు."

## Tractor / Farmer

Common angles:

- Farmer struggling with bulls -> friend introduces tractor -> finance/showroom -> fast field work -> family happiness.
- Before/after productivity proof.
- Dealer trust and easy finance.

Useful Telugu lines:

- "రైతు కష్టానికి నమ్మకమైన తోడు."
- "శక్తి, నాణ్యత, నమ్మకం - ప్రతి అడుగులో మీతో."

## Quality Rules

- Avoid generic creator-growth advice.
- Make the product visible by Scene 2 or Scene 3.
- Include concrete offer/proof if brief provides it.
- If brief says cartoon, write visual directions suitable for animation.
- If brief says emotional, include family/aspiration payoff.
- If brief says mass, make lines short and punchy.
