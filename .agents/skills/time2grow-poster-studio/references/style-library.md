# Style Library

Use one style for the full concept set unless the user explicitly requests mixed directions. These are quality directions and token sets, not copied templates.

## value

Visualize Value. Use for SaaS, B2B, analytics, reports, consulting, and educational business proof.

- Palette: light background, graphite ink, quiet blue accent.
- Typography: Inter or similar clean sans.
- Layouts: bottom, centered, facts.
- Motifs: grid, chart line, dashboard, device, network.
- Avoid: luxury serif, heavy discount bands.

## premium

Minimal Premium. Use for jewellery, beauty, fashion, launches, high-ticket services, luxury local brands.

- Palette: charcoal or off-black, warm brass accent, ivory ink.
- Typography: Fraunces or editorial serif for headline, clean sans for details.
- Layouts: centered, bottom.
- Motifs: soft gradient, product photo, editorial crop.
- Avoid: red urgency badges, loud gradients.

## bold

Bold Emotional. Use for brand films, announcements, strong statements, events, political-style energy, high-impact campaigns.

- Palette: near-black, high-contrast ink, vivid accent.
- Typography: Anton or strong condensed display plus clean sans.
- Layouts: centered, bottom.
- Motifs: large shape, dramatic photo, spotlight.
- Avoid: too many words.

## edu

Educational. Use for guides, explainers, how-to posts, coaching, financial literacy, clinics, training.

- Palette: friendly light background, teal or blue accent, amber support.
- Typography: Poppins, Montserrat, or Inter.
- Layouts: facts, bottom.
- Motifs: numbered cards, clean diagram, icon-like linework.
- Avoid: dense paragraphs and tiny labels.

## direct

Direct Response. Use for sales, offers, urgency, launches, lead-gen, local business promos.

- Palette: dark or high-contrast base, yellow/white offer band, red or orange badge only when justified.
- Typography: bold sans with strong CTA.
- Layouts: band, bottom.
- Motifs: product photo, offer strip, badge.
- Avoid: invented scarcity, fake discounts, unreadable price blocks.

## signature

Ad96/time2grow Signature. Use for authority, executive intelligence, AI marketing OS, dashboards, strategy, agencies.

- Palette: deep navy, ivory, muted blue, gold accent.
- Typography: refined serif or strong sans headline, clean sans body.
- Layouts: bottom, centered, facts.
- Motifs: hairline frame, network, dashboard grid, controlled glow.
- Avoid: generic AI purple gradient.

## Custom Hex

When the user supplies hex colors, map them to:

- `bg`: dominant background.
- `ink`: main text.
- `muted`: secondary text or lines.
- `accent`: CTA and key highlight.

If contrast fails, keep the user accent but adjust `bg`/`ink` for readability.
